Proof scope

For Two Guards, Prolog checks every possible world with iterative deepening. Coq independently checks the generated Boolean theorem, satisfiable assumptions, graph consistency, door decoder, explicit choices and existential strategy witness. No admitted proofs are generated.

For named scenarios, Prolog searches a finite rule graph. Coq checks the derivation as a theorem conditional on those visible facts and rules. This does not recheck the arithmetic, temporal definitions or source lemmas in the original Isabelle/HOL theories. Those require the native Isabelle build. Imported custom THY files are restricted to the supported declarative grammar; arbitrary HOL/ML is not executed.

Storage

Sessions, drafts, reflections, settings and evidence use IndexedDB. The model uses the origin-private file system. App files and proof libraries use Cache Storage. There are no accounts, analytics, learner uploads or inference API calls. Browser storage may be cleared or evicted; export personal work before changing device or origin.
