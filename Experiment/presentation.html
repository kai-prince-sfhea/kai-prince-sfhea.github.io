PRESENTATION RUNBOOK

My reasoning. My device.

A live feasibility demonstration of the HE-Tech proposal: a private argumentation sandbox with learner-reviewed interpretation and independent formal checks.

Prepare on each device

  1. Use Device setup to consent to the download and install all assets.
  2. Run the full benchmark, including Gemma. Export its device details, versions, hashes, timings and failures.
  3. Install to the home screen. Enable cache-only mode. On mobile, turn on airplane mode, close and reopen the installed app.
  4. Use a fresh attempt. Keep a saved JSON backup. Allow several minutes for first-use GPU compilation.

A cached screen is not evidence of offline inference: submit and verify a new thought after disconnecting.

Five-minute reasoning demonstration

  1. Control: open Preferences, choose guidance and reduce visual detail. Explain that the optional timer pauses during processing and never locks the learner out.
  2. Review: submit “If the asked guard is a liar, their direct answer about this door matches its safety.” Check Gemma’s interpretation before confirming. The false reasoning should receive a counterexample.
  3. Refine: submit “If I ask whether the other guard would say this door is safe, the answer is opposite to the safety of this door, whichever guard I ask.” Confirm only if the interpretation matches.
  4. Separate knowledge and action: show that the scenario remains unfinished. Knowing which door is safe does not automatically supply the learner’s choice rule.
  5. Choose: submit “For that question, I go through the other door if and only if the answer is yes.” Review both answer branches and confirm.
  6. Inspect: open Inspect logic & code, then the graph view and both engine sources. Show the closed kernel theorem, original player quotation and goal check.
  7. Reflect: open the debrief: exploration, the direct route, transferable concepts. Write a reflection and export it.

If interpretation is inaccurate, demonstrate correction rather than confirming it. Translation fidelity is itself an evaluated part of the prototype.

Show transfer and authoring

Choose among three murder investigations of increasing complexity. Explain that a suspicion score is not a conviction. Import a bundled THY example and inspect its propositions. Download and edit the small custom THY template to author a new case.

Browser investigation proofs are conditional on their finite rule representation. The original HOL theory is shown as reference; browser verification does not execute arbitrary imported Isabelle code.
