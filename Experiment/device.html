This checks this browser’s secure origin, GPU access and local storage. It downloads no model and requests no microphone permission. Model memory limits still need the device benchmark.

1 · Install the local tools

Download Gemma 4 E2B (2.01 GB) and the browser runtimes (size shown below). Use a device with WebGPU and sufficient memory. The browser export’s QAT provenance is unconfirmed; this build uses the approved E2B fallback. No cloud inference is used. After consent, the model downloads directly from Hugging Face; browser runtimes download from this website. Your thoughts are never sent to the model host.

The proof tools are SWI-Prolog and the Coq 8.20.1 kernel, the predecessor of Rocq. Two Guards uses exhaustive Boolean proofs. Other scenarios certify deductions from the displayed finite rules; the problem-only Isabelle/HOL files remain inspectable references.

Pressing Download consents to the model, runtimes and any selected encoder pack. No thought text is uploaded.

No large download starts without pressing the download button. Optional packs require separate consent; a consented pack download can temporarily fetch only its listed assets in cache-only mode.

On mobile, use your browser’s Add to Home Screen / Install app. On desktop, use its Install app menu. Initial installation requires HTTPS (localhost also works).

Dynamic prompt examples · recommended encoder

EmbeddingGemma selects an independent example to help Gemma interpret a thought. Selection runs locally; it cannot add facts, verify a claim or replace my review. Gameplay remains in English. This is an experimental option; faster or more accurate responses are not guaranteed.

No learner profile is inferred. Examples include three script expertise levels; the closest compatible wording is selected.

2 · Benchmark this device

Runs the real compiler, Prolog, proof kernel and (optionally) Gemma. For comparable evidence, record three cold and three warm runs on each device under the same power conditions. The latest 12 completed reports stay on this device. Failures and unavailable features remain visible. This creates separate test sessions and does not change my gameplay.

Player journeys always use real Gemma and both proof tools. Preset meanings are checked before confirmation; inaccurate interpretations fail the journey. Profiles describe synthetic scripts, not measured human expertise. Cold mode resets engines before each journey; warm mode retains them. Static assets stay cached. The procedural Evidence Review and new attributed activities are covered by feature checks rather than these six fixed player scripts.
