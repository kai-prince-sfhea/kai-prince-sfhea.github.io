THREAD · ON THIS DEVICE

Ready wherever I think.

All thoughts, scenarios, reflections and benchmark results stay in this browser. After installation, interpretation and proof checking work without the server or internet.

1 · Install the local tools

Download Gemma 4 E2B (2.01 GB) and the browser runtimes (size shown below). Use a device with WebGPU and sufficient memory. The browser export’s QAT provenance is unconfirmed; this build uses the approved E2B fallback. No cloud inference is used. After consent, the model downloads directly from Hugging Face; browser runtimes download from this website. Your thoughts are never sent to the model host.

The proof tools are SWI-Prolog and the Coq 8.17.1 kernel, the predecessor of Rocq. Two Guards uses exhaustive Boolean proofs. Other scenarios certify deductions from the displayed finite rules; the original Isabelle/HOL files remain inspectable references.

No large download starts without pressing the download button.

On mobile, use your browser’s Add to Home Screen / Install app. On desktop, use its Install app menu. Initial installation requires HTTPS (localhost also works).

2 · Benchmark this device

Runs the real compiler, Prolog, proof kernel and (optionally) Gemma. Failures and unavailable features remain visible. This creates separate test sessions and does not change my gameplay.

3 · Demonstrate offline operation

Install the tools first. Enable cache-only mode, then close and reopen the app. On a physical mobile device, also switch on airplane mode. Submit a new thought, review it and verify it. A successful cached page load alone does not demonstrate offline inference.
